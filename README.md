# 🀄 Smart Riichi Mahjong Play-Board (智能日本麻将数码精算风盘)

这是一个基于 **ESP32** 主控设计的**日本麻将智能精算风盘计分系统**。该项目打通了硬件传感器、数码管显示器、物理按键矩阵、语音/BGM 播放引擎，并搭载了本地无线 Web 控制后台，实现了日麻对局中**点数计算、顺位排列、自动立直检测、精算转账、掷骰开门、连庄本场棒管理、多媒体处刑曲播放**等全套对局支持。

---

## 🌟 核心功能特性

### 1. 🎛️ 硬件精算与多维人机交互
* **ESP32 主控核心**：多线程无缝调度网页端、串口音频驱动、I2C 端口扩展及传感器扫描。
* **4路 TM1637 数码管**：共享同一时钟，物理独立片选。实时动态显示四家分值、当前排名，庄家小数点亮灯及连庄本场数点位。
* **PCF8575 端口扩展**：采用 I2C 驱动低延迟 4x4 矩阵键盘，以及 4 路庄家 LED 大按键。
* **大按键掷骰功能**：一键物理随机掷骰子（2-12），并在数码管上根据日麻方位规则闪烁开门方位。

### 2. 🧮 纯正日麻结算与模式自适应
* **三麻/四麻自适应**：支持物理开关或代码硬切：
  * **四人麻将（四麻）**：初始 25,000 点，总点数 100,000。
  * **三人麻将（三麻）**：初始 35,000 点，总点数 105,000，开机即自动切断北家（P4）的指示灯与数码管并锁死输入。
* **精准本场棒（连庄棒）点数割让算法**：
  * **荣和（放铳）**：由放铳玩家全额支付，三麻模式下每本场付 `200`，四麻下每本场付 `300`。
  * **自摸**：其余各输家平分支付本场点，自适应换算为每位输家各支付 `100 * 本场数` 点。
* **便捷点数录入**：键盘输入映射为绝对点数，输入 `1000` 即代表 `1000` 点，免去心算折算。

### 3. 🎸 电影级立直音效状态机
* **常规对局**：循环播放普通对局 BGM。
* **立直爆发**：霍尔传感器检测到立直棒投入 1 秒后自动触发，自动扣除 1000 点入池，阻断常规背景音，大声点播该方位的专属**立直爆点语音**。
* **激昂处刑曲**：语音播放完毕后，自动无缝切入局内专属**激昂处刑曲**并进入无限循环，直至该局和牌结算后重置。
* **局间智能静音与锁定**：结算成功或触发流局后，系统自动判定为待机状态（`isGameActive = false`），**阻断一切霍尔误触发，且自动将背景音乐关闭静音**。只有当下一局庄家掷骰子开局后，BGM 才会重新响起。

### 4. 🌐 极简无线裁判接管端
* **WiFi 局域网控制**：开机后 ESP32 会自动接入 WiFi 并部署无线 Web 服务器，可在手机浏览器直接访问。
* **实时大盘监控**：包含局势总览，实时点数、顺位、庄位、立直锁以及当前连庄数与立直池存留。
* **无线接管操作**：支持无线进入转账/加减分模式、无线强改庄位（具备二次安全防误触弹窗保护）、远程微调立直池与连庄数。

## 🛠️ 硬件引脚映射 (Pinout Map)

系统基于 ESP32-WROOM-32 模组开发，主要引脚配置如下：

* **I2C 总线 (PCF8575)**：`SDA = GPIO 13`, `SCL = GPIO 14` (地址 `0x20`)
* **数码管共享时钟 (TM1637)**：`TM_CLK = GPIO 22`
* **数码管数据脚 (DIO)**：`P1 = GPIO 21`, `P2 = GPIO 19`, `P3 = GPIO 18`, `P4 = GPIO 5`
* **霍尔传感器 (立直检测)**：`P1_Hall = GPIO 26`, `P2_Hall = GPIO 27`, `P3_Hall = GPIO 33`, `P4_Hall = GPIO 25`
* **三麻/四麻物理开关**：`PIN_3PLAYER = GPIO 2`, `PIN_4PLAYER = GPIO 15`
* **音频串口 (MH2024K)**：`TX = GPIO 16`, `RX = GPIO 17` (使用 ESP32 硬件 Serial2，Baudrate 9600)

> [!WARNING]
> **硬件设计注意点**：由于 PCF8575 初始化时底层会短暂重置 I2C 引脚回默认的 21 和 22。为防止与共享此引脚隔开的 P1 屏幕和 CLK 发生通信锁死冲突，固件在 `pcf8575.begin()` 后添加了二次重定向时序，硬重置 I2C 绑定至 13 和 14 引脚。

## 🚀 固件编译与部署

1. **环境准备**：使用 **Arduino IDE (2.0+)** 或 VSCode PlatformIO。
2. **开发板支持**：安装 `ESP32` 支持包（推荐版本 `2.0.x` 以上）。
3. **安装依赖库**：
   * `PCF8575` (由 Renzo Mischianti 维护)
   * `TM1637Display` (由 Avishay Orpaz 维护)
   * Arduino 官方 `Wire` 与 `WiFi` 库。
4. **修改 WiFi 配置**：
   打开 `web_server.h`，修改顶部的 WiFi SSID 和密码：
   ```cpp
   const char* wifi_ssid     = "您的路由器SSID"; 
   const char* wifi_password = "您的路由器密码"; 
   ```
5. **上传代码**：配置开发板为 `ESP32 Dev Module`，波特率选择 `115200`，点击编译并烧录。

## 🎮 玩家基本对局操作说明

### 1. 开局摇骰
* 开机通电后，东家（P1）物理大按钮会亮起指示灯，数码管显示 `0350`。
* 东家（P1）按下自己面前的大按钮，自动抛掷骰子，东家屏幕和摇出的对应方位屏幕会显示骰子点数。
* BGM 音乐此时正常播放，局内立直检测进入激活状态。

### 2. 霍尔立直
* 玩家在局中打出立直牌并横放立直棒至磁吸霍尔感应区时，传感器稳定感应 1 秒以上，触发系统自动扣除 `1000` 点加到立直公积金池中。
* 喇叭会中断常规背景音乐，大声播放该方位的立直人声，随后切入高燃处刑曲并一直循环。

### 3. 和牌点数结算
* 赢家物理按下自己名字缩写的字母键（`E/S/W/N`）进入**精算转账模式**。
* 输家（一个或多个）也分别按下自己对应的字母键（此时数码管开始闪烁提示）。
* 赢家使用键盘数字键输入该局的和牌点数（如输 `1000` 点，屏幕即显示 `1000`）。
* 赢家按下键盘的 **`E/S/W/N`**（赢家自身按键）进行确认。
* **结算完成**：系统自动结清分值，如果是闲家和牌则自动下庄（顺延庄家指示灯），回收全部立直公积金，连庄数逻辑自动判断。同时**BGM 停播静音，系统回到待机锁定状态**，静静等待下一次掷骰开始。
